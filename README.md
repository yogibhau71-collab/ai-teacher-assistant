# AI Teacher Assistant

An Open-Source AI-Powered Teaching and Learning Platform.

## About the Project

AI Teacher Assistant is an open-source educational platform designed to help teachers and students create learning materials, practice questions, lesson plans, and educational resources.

The project aims to support multilingual education, especially Marathi and English.

## Planned Features

- AI-powered Question Paper Generator
- Multiple Choice Question (MCQ) Generator
- Marathi and English Learning Support
- Lesson Plan Generator
- Educational Notes Generator
- CTET, TET and Competitive Exam Preparation
- Teacher Dashboard
- Student Learning Assistant

## Project Goals

1. Reduce teachers' time spent preparing educational materials.
2. Support regional-language education.
3. Make educational resources more accessible.
4. Encourage open-source collaboration.
5. Build a useful and privacy-conscious educational platform.
